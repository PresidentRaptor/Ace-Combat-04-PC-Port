# Code of Conduct

This project welcomes respectful participation regardless of background,
identity, experience or ability. These expectations apply to repository issues,
pull requests, discussions, reviews and other project-managed spaces.

## Expected behavior

- Discuss code and evidence; criticize ideas without attacking people.
- Be patient with new contributors and accept constructive corrections.
- Respect differing experiences, accessibility needs and personal boundaries.
- Credit others' work and keep discussions relevant to the project.

Harassment, discriminatory language, threats, sexual attention, personal insults,
sharing private information without consent, spam and repeated disruption are
not acceptable. Do not pressure others for game files or access to private data.

## Reporting and enforcement

The maintainer is [PresidentRaptor](https://github.com/PresidentRaptor).
Use an existing private maintainer contact channel if you have one. Otherwise
choose **Private contact request** in this repository's issue chooser and request
a private route. Do not include incident details, names of affected people or
personal information in that request. GitHub profiles do not provide a built-in
direct-message inbox. No public contact email is published for this project.

Maintainers will consider reports in context and limit disclosure of sensitive
details where possible. They may edit or remove content, request a correction,
warn a participant, restrict participation temporarily or ban repeated/severe
misconduct. Decisions should be proportionate to the behavior. A participant may
request reconsideration through the same private contact process.

For imminent threats or abuse on GitHub, GitHub's own reporting mechanisms
remain available. This policy does not promise a confidential hotline or a
fixed response time.
