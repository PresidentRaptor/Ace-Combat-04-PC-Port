# Getting help

Start with [installation and troubleshooting](README.md), the
[compatibility checklist](docs/compatibility.md), and [release notes](CHANGELOG.md).
Use this repository's issue chooser for a bug, feature proposal or support
question. Requests are handled as maintainer time allows; support is not a service
with a guaranteed turnaround.

For a bug, include your version/commit, mission, camera, Windows version,
GPU/driver, controller, rendering settings, mods and reproduction steps.
`DIAGNOSTICS.bat` creates `diagnostics.log`; review it for personal information
before attaching it. A cropped screenshot can help explain a visual defect.

Do not upload ISOs, original executable files, generated game code, extracted
assets, full graphics captures or memory dumps. We do not provide game downloads
or help find them. Maintainers reproduce issues using their own game copies.

Report AC4 problems here, not in the upstream AC5 project. For sensitive security
or conduct concerns, use the [security](SECURITY.md) or
[conduct](CODE_OF_CONDUCT.md) reporting process. The issue chooser includes a
minimal request for a private contact route; do not put sensitive details there.
